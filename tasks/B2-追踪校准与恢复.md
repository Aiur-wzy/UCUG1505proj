# B2：追踪、校准与平滑恢复

负责人：B。状态：待实施。关联验收：I03、I04、C02。

## 1. 目标与范围

把有效的颜色候选转换为稳定的双手观测和每位玩家的角度/力度。提供取色、站位与距离校准；遮挡、歧义和换人后必须重新就绪。

本卡只输出观测和有效性，不发送五种游戏命令，不推进游戏阶段。首版档案存在应用内存即可；刷新后允许重新校准，无需账号或存档系统。

依据：[手册](../Flock-and-Flick-开发手册-v2.0.md)第 7、8、15 节及 [defaults](../interface-v1.1/defaults.json)。

## 3. 实施要求

1. anchor/guide 代表两只手，不代表两位玩家。初次捕获要求互动区中存在唯一可信候选；后续按面积与历史位置关联。两个相近候选无法可靠区分时报告歧义，不强选最大的色块。
2. 以处理图宽 W 做一次坐标适配：u=1−x/W、v=y/W。两轴都除 W 保持角度/距离比例；视频预览与叠加使用同一镜像规则，不再在 Worker 里镜像。
3. 两色均可信且未缺失、跳变或过近时才输出 validPair。候选突然跳变、单手缺失、同色干扰造成歧义时立即失效；不沿用旧坐标伪装新观测。正常近距离释放仍需两色可分，不能仅因 r 小就判失效。
4. 取色采样避开背景和高光，色相计算处理 0°/360°环绕；按共享参数检查颜色可分性。颜色阈值改变后交 B1 更新 configVersion，并等待新配置结果。
5. 每位玩家分别采样中立方向、近距离与远距离，各约 1 秒；只收有效帧。dClose、跨度等条件使用 defaults.calibration；不合格时指出重采步骤，不能保存除零档案。
6. 档案保存 playerId、版本、颜色配置、theta0、dClose、dFar、方向符号及必要的选球范围。先确认左右移动映射正确，再允许保存；玩家切换不能沿用另一人的距离。
7. 先对有效质心按真实 dt 指数平滑，再按手册计算角度、r 和 power01。角度差归一到 −180°至 180°，最终正值仍表示向右；输出限幅。r 留在 B 内，不进入游戏合同。
8. 重获目标后重新初始化滤波。先持续有效 500ms，再保持 r≤0.20 的中立姿态 500ms，置 rearmed=true；使用样本时间连续计时，不靠帧数累加。
9. 新 session/turn/player/source、重新校准、追踪失效清除 rearmed。普通 phase/context 变化和 motionEnabled 从 false 变 true 不清除此锁存，只由 B3 清手势候选。门控关闭时仍继续追踪与恢复。
10. 校准取消/停止不覆盖原有效档案；返回明确的失败结果。新增候选选择阈值只放在 B 内可调参数并记录依据，不改变公共角度/力度单位。

## 4. 验收

| 编号 | 输入或操作 | 通过条件 |
| --- | --- | --- |
| B2-01 | 唯一两色候选 → 同色等可信双候选 → 单手缺失 → 大幅跳变 | 唯一时有效；后三种情况下失效并给出原因，不输出可用于确认的旧样本 |
| B2-02 | 处理图中左右/上下已知位置和画布缩放 | 只镜像一次；横纵比例正确，显示中心与计算位置一致 |
| B2-03 | 近距离不足、远近跨度不足、采集中断或同色阈值重叠 | 校准不能成功保存；无 NaN/除零；提示具体重采步骤 |
| B2-04 | 使用已知 theta0、远近距离，输入中立/左右转动/近远拉伸 | 角度方向正确、限于既定范围；r 与力度符合手册公式，r≤0.30 时力度为 0 |
| B2-05 | 以不同采样间隔输入相同运动序列；再丢失/重获 | 滤波依据 dt 而非帧数；重获不从旧位置缓慢拖回；没有无效帧参与平滑 |
| B2-06 | 有效对不足 500ms；之后有效 500ms＋中立 500ms；中间插入无效帧 | 不足时不就绪；完整顺序才 rearmed；插入无效帧使确认重新开始 |
| B2-07 | rearmed 后切 adjust/armed、开 motion 门；再换 turn/玩家/来源 | 普通阶段与开门保留锁存；身份变化清锁存，要求重新就绪 |
| B2-08 | A/B 使用明显不同的远近距离档案交替校准和切换 | 各自映射一致；校准失败不覆盖另一人的档案；读取到正确版本 |
| B2-09 | 真人穿戴手套，固定站位做左右转动、拉开、遮挡和回归 | 显示与本人动作一致；恢复需重新确认；真实效果以现场记录为准 |
