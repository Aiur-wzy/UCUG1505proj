# A2：投掷物理与特殊球

负责人：A。状态：待实施；已有八球物理验证示例可复用。关联验收：G04、G05、C03、P01。

## 1. 目标与范围

让一只球按游戏锁定的角度与力度发射，滑动、碰撞、出界和停止；后续投掷可改变已有布局。先交付普通球，再完成排斥球。始终只有一个 Phaser 内置 Matter 世界。

包括：逻辑场地、固定步长、发射起点选择、碰撞/滑动、特殊效果、稳定判定、场景快照和预计路径数据。库存、玩家轮换和计分由 A1/A4 处理；视觉样式由 A3 处理。无需预测多次碰撞或特殊球的完整未来结果。

依据：[总体手册](../Flock-and-Flick-开发手册-v2.0.md)第 4、6、14、15 节及 [defaults](../interface-v1.1/defaults.json)。

## 3. 实施与接入

1. 使用手册的 1000×700 逻辑场地，屏幕缩放不改变规则坐标。关闭重力、关闭自动物理更新，按既定 60 Hz 步长推进；每帧最多追赶五步，暂停/后台恢复不补跑大段积压。
2. 进入选球阶段时，按 defaults.world.launchCandidatesX 寻找与既有球不重叠的发射位置，写入游戏本投状态。预览与建球共同使用这一位置，中途不能各算一次不同起点。
3. 接收 A1 的 shotId、玩家、球类、起点、锁定角度/力度；速度按手册转换，0 力度仍是最低速度。同步建球失败清理本次对象并向调用方报告异常；不操作库存。
4. 正式场地边缘不设反弹围墙。整只圆盘离开场地后移除物理实体，保留 outOfPlay 记录，并结束该球尚未完成的本地效果，避免永远等待 pending；出界不退库存。场景快照保留 id、ownerId、typeId、位置、半径和 inPlay。
5. 排斥球第一次连续低速达到触发时间后仅激活一次；作用范围、持续时间和每步速度变化取 defaults.effects.repel。零距离使用稳定的 id 规则选方向，避免除零和随机抖动。
6. 每个模拟步先推进物理，再推进效果，最后判断结束。有 pending/active 效果时不能结束一投。全部在场球达到低速并保持规定时长后清零残余速度，给 A1 一次本投完成回调。
7. 不把球冻结成无法再被撞动的静态障碍。20 秒诊断超时只提示异常/重试，不强制宣布比赛结果。
8. 预计路径用同一滑行衰减近似自由运动，首个球/障碍碰撞处截断并标记；若先出界，在边界标记预计出界。向 A3 返回绘制数据，不在每次输入中重新创建物理世界。

初始场地和最多八球下，既定候选数量应足够；仍须处理“找不到合法起点”：保持未发射、不扣库并显示诊断，不把球硬塞进重叠位置。

## 4. 分段交付

- **A2 基础段**：普通球、固定步长、出界、稳定结束与预计路径。完成后立即供 A3/J1 首次联调。
- **A2 完整段**：排斥球、异常恢复、资源清理与完整效果验收。未完成时不能把整张 A2 标为全部通过。

## 5. 验收

| 编号 | 操作或输入 | 通过条件 |
| --- | --- | --- |
| A2-01 | 0°/−50°/+50°和 0/1 力度各发射；改变画布显示尺寸 | 0°向上、正角向右；力度范围对应既定速度；缩放不改变逻辑轨迹 |
| A2-02 | 锁定后修改输入，再触发真实发射 | A2 只读取原锁定参数与固定起点；不追读输入端实时值 |
| A2-03 | 普通球撞击旧球；随后出界 | 旧球可被推动；整盘出界才移除；没有边界反弹或库存返还 |
| A2-04 | 排斥球进入低速触发区；过程中再次满足低速 | 效果仅激活一次；pending/active 期间无完成回调；效果结束并稳定后只回报一次 |
| A2-05 | 构造两球同位置、效果半径边缘和范围外快照 | 无 NaN/随机方向；范围外不施加排斥；纯函数边界符合参数 |
| A2-06 | 发射起点被旧球占用；重新开始一次投掷 | 按候选顺序选择不重叠起点；预览箭头与实际球生成位置一致 |
| A2-07 | 运动中暂停、切后台再回来 | 暂停时物理/效果时钟均停止；恢复无大步穿透或额外完成回调 |
| A2-08 | 预计线遇球、预计出界、自由滑行 | 预计线在首个事件处结束并标记；界面标“预计”；不声称精确模拟后续碰撞 |
| A2-09 | 超过诊断时限仍未稳定；连续重置场景三次 | 显示诊断/重试；不自动计分；旧球、效果、计时和监听均释放 |
