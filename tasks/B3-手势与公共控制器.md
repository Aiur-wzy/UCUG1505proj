## 3. 公共方法与生命周期

- `setContext(context)` 可在 start 前调用，保存最新上下文。contextId 改变清手势候选；同 id 的连续预览通知不重置停留。身份变化另通知 B1/B2，使旧流与重新就绪失效。
- `start(host)` 由用户点击后调用，等待相机和 Worker READY，再完成启动；重复启动合并为同一进行中的操作。失败报告真实原因并结束 pending 状态，不假装校准已通过。
- `calibrate(playerId)` 在 host.cameraMount 中委托 B2 校准，返回 CalibrationResult；双人分别调用，档案按玩家保存。
- `stop()` 关闭 B1、取消校准和手势、清理面板与自己注册的监听。未完成的校准返回 ok=false 和明确原因，不能让 Promise 永久等待；重复 stop 无副作用。

控制器不导入 Phaser，也不读取场景球对象。使用 host.now；feedback/command 的 atMs 来自最新参与识别的样本，不能用提交时刻刷新旧观测。

## 4. 每个有效样本的处理顺序

1. 读取该样本对应的上下文与 B2 观测，拒绝旧身份或时效失效；更新本地手势的可用条件。
2. 先 `host.report` 再尝试命令。无效时立即清候选并报告，不能带着上一帧的坐标继续停留/释放。
3. report 可能使 A 同步发布新的 contextId。若处理期间上下文变化，本样本不再提交命令，等待新上下文下的新帧；不能修改旧样本标签后继续发送。
4. motionEnabled=false 时仍追踪、校准和报告，以便 A 重新开门，但不提交游戏命令。还须检查 previewSource=motion、inputEnabled、allowedCommands 和对应动作开关。
5. 正常 adjust 中按最新样本发送 PREVIEW_SHOT，最多 20 Hz；不等待稳定。非选定来源不发送预览。
6. 对离散命令使用唯一编号，每个动作候选最多提交一次。setContext 回调不递归 submit；除“当前帧预览后锁定”这一合同规定顺序外，阶段变化后的下一个动作等待新样本。
7. 被拒绝时清相应候选，读取最新上下文重新形成动作；不靠重复发送新 commandId 试到成功。内部 submit 异常记录诊断并停止当前候选，不把失败写成 accepted。

## 5. 手势规则

| 动作 | 形成条件 | 输出与边界 |
| --- | --- | --- |
| 选球 | select；rearmed 且有效；r≤0.20；按库存顺序分槽，中点在同槽保持 600ms，槽间迟滞 0.04 | 反馈 focusedBallId/进度，完成后一次 SELECT_BALL；零库存不能确认 |
| 实时预览 | adjust；有效且已校准/重新就绪 | 当前角度/力度即刻用于 PREVIEW_SHOT；无确认停留 |
| 可选锁定 | 开关开启；r≥0.30；700ms 窗内角度峰峰差≤4°、力度峰峰差≤0.06 | 先提交该帧 PREVIEW_SHOT，接受后再 ARM_SHOT 空载荷 |
| 可选释放 | 收到 armed 时有效且 r≥0.30 才建候选；之后新帧开始检测 | 相对锁定时下降 0.08 开始计时，800ms 内达到 r≤0.12 并保持 100ms，发送一次空载荷 FIRE |
| 可选返回选球 | adjust 中先拉到 r≥0.30，再近合拢并保持 600ms；取消开关开启 | 发送 CANCEL_SHOT；避免刚选完球立刻返回 |

armed 的五秒超时由 A 处理，B 只显示并响应新上下文。慢合拢使释放候选作废；若取消开关开启，按手册取消锁定；取消未开启时不发送禁用命令，仍保留键鼠取消/发射及游戏超时。手套缺失由 A 的反馈失效边沿解除锁定，不依赖取消动作开关。

FIRE 不带角度与力度，合拢造成的实时距离变化不应降低已锁定发射力度。进入 armed 时条件不足就不创建释放候选，键鼠 Space 仍能按游戏规则发射。

## 6. 独立与接入验收

| 编号 | 操作或输入 | 通过条件 |
| --- | --- | --- |
| B3-01 | 使用模拟 host 完成 setContext → start → calibrate → stop；启动中停止再重开 | 四个公开方法符合类型；pending 操作能结束；迟到回调不复活旧会话 |
| B3-02 | 同一槽停留不足/达到 600ms，跨槽边界、零库存 | 只在完整有效停留后选一次；有迟滞；无库存不提交 |

| B3-04 | 默认动作开关；人为做锁定/释放/取消手势 | 只输出选球与预览；可选命令均不发送，键鼠结果由 host 正常接收 |
| B3-05 | 处理中 host.report 改变 context；换玩家、换 source 或样本过期 | 当前旧样本不再提交；身份变化清候选；新玩家重新就绪；不重写样本时间 |

| B3-10（可选） | 各开关单独切换、adjust 中先拉开再合拢 | 只发当前启用动作；关开动作不会沿用旧候选立即触发 |
