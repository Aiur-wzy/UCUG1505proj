# 规则 v2.1 验收 · 2026-11-07

用户要求的三面墙、调试预测开关、四种球、方形计分、翻倍最大初速度均已实现。库存按用户确认配置为每位玩家每种各 1 只。更新范围见 [规则与调参说明](../../游戏规则变更-v2.1.md)；原 A Part 记录和截图保留为初版历史证据。

## 验证环境与结果

Windows x64，项目独立 Node 24.22.1，Edge 156.0.4314.58。使用独立的无界面浏览器配置，不控制个人浏览器，不请求摄像头。

- 类型检查、67 项 Vitest 测试、构建均通过。
- `scripts/browser-check.mjs` 在 5173 开发版、4173 构建版均通过 18 项检查，没有页面运行错误或资源错误。
- 查看了桌面菜单、正式局内、调试预测、结果页和 390px 窄屏截图；四球卡片与方形场地可见，无横向溢出。
- defaults / fixtures 的工程与接口镜像一致；公共协议 1.1、Worker 1.0、产品依赖与锁文件不变。

| 需求 / 行为 | 实际检查结果 |
| --- | --- |
| 三面墙 | 满力度、0° / −50° / +50° 的合法普通球投掷，分别捕获顶墙 / 左墙 / 右墙速度反向；没有侧边或顶部离场。停稳重开后只保留 3 个静态墙体 |
| 底边开放 | 独立物理夹具从 `(500,680)` 朝下生成球，完全越过底边后标记离场并移除。此项使用构造起点与 180° 方向，明确不属于正常玩家可提交的投掷 |
| 隐藏预测 | 正式页无调试开关、预测状态为 false；默认只有短箭头。联调页默认未勾选，开 / 关前后完整游戏状态相同 |
| 新球输入 | 4 个库存选项可见，键盘 3 / 4 可选择吸引 / 粘黏，每位玩家各类型仅 1 次可用 |
| 吸引 | 两次合法投掷使邻球位于吸引范围；气场激活时球距约 118.88，结束停稳约 83.96，实际距离缩短约 34.92 |
| 粘黏 | 普通 0°/25% 后粘黏 0°/30% 首次碰撞生成 1 条连接，球距约 35.92；暂停期间不动，恢复并停稳后连接归零；后续碰撞不再次触发 |
| 粘黏重开 | 连接仍有效时重试，清除球和约束，墙体保留，无旧连接影响新局 |
| 效果结算 | 排斥和吸引均依次 pending → active → done，激活数 1；过程仍处于当前 resolving，全部稳定后才到下一回合 |
| 方形计分 | 单人角落、最高分区域、边界；双人圆盘触角 / 擦边 / 无相交，以及原七个轴向计分样例通过 |
| 力度 | 最低初速度 3，满力度 26，至少为旧值 13 的两倍；三面墙测试使用真实满力度投掷 |
| 五关可达 | 同一组四次合法投掷分别实得 9 分，达到目标 3 / 4 / 5 / 6 / 7；无位置或比分注入 |
| 失败 / 重试 | 四种球分别以 0% 投掷，实得 0 分；失败后重试恢复新局 |
| 双人库存与回合 | 3 场完整八投；每人四种球各 1 只；先手 A → B → A，比分 1:0 / 0:1 / 1:0；结算时无活动气场和粘黏连接 |
| 既有操作 | 正式页实时投掷、锁定 / 取消、暂停 / 恢复、模拟手套预览与失联、DOM 焦点、重复 FIRE、OpenCV 合成图诊断继续通过 |

五关复现序列：普通 −9°/25%，吸引 0°/25%，粘黏 +9°/25%，排斥 +20°/24%。此序列证明可达，不代表关卡难度或最优策略。整局均通过真实 InputHost 提交，按固定步长加速运行同一 Phaser Matter 世界，不替换其物理计算。
