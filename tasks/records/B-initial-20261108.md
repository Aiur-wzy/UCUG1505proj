## B 浏览器覆盖

1. 带噪声红绿 RGBA 图经真实本地 OpenCV Worker，候选数和已知质心符合预期，不申请摄像头。
2. A/B 各自三次连续姿势采样，保存独立档案。
3. 重新就绪 → 停留选球 → 同一双手向量实时改变方向/力度，无稳定停留等待。
4. 键鼠锁定后移动手套不改变冻结参数；B 不产生锁定、发射或取消命令。
5. 换玩家后清就绪，使用该玩家的距离档案重新确认。
6. 缺手解除现有体感锁定；持续缺手不会反复撤销键鼠主动锁定。
7. 双绿的两个连通域对应两只手，不复用同一色块。
8. 保留颜色的局部重新校准；取消后保留之前有效档案。
9. 双绿合并、近乎竖直交叉、重新捕获时出现第三个同色块均失效。
10. 高密度小噪声和降低亮度下恢复；最多一个在途帧。
11. 390px 页面宽度无横向溢出；桌面与游戏接入截图已检查。
12. 连续三次启动/停止释放管线，pending 校准得到结束结果。
13. 模拟拒绝权限正确报告 CAMERA_DENIED，不无限重试。
14. 用 Canvas 生成合成 MediaStream，经过 video.play/视频帧采集/Worker，停止后视频轨道结束。
15. A 的游戏发现 B 工厂，模拟像素完成校准、预览、键鼠确认、实际物理投掷并进入下一投。
16. 浏览器运行时和 HTTP 错误为零。

B 浏览器的紧凑结果见 [JSON 记录](B-initial-browser-20261108.json)。截图和完整本机日志保存在 Git 忽略的 `.local/motion-check/`。A 回归额外覆盖单人五关、三场双人局、特殊球生命周期、边界、粘黏、冻结/取消和原 OpenCV 原型。

## 未完成的验收

- 本次没有访问物理摄像头，也没有真人戴手套操作。真实允许/拒绝权限、设备断开、光照、背景、运动模糊、手套贴合和不同站位尚需现场记录。
- 尚未测真实输入延迟的中位数/P95、稳定视觉帧率、20 次选球成功率或完整真实体感双人对局。
- 体感锁定、释放发射、取消属于可选段，当前不实现；由键鼠完成。
- 双绿无法在完全重叠/遮挡中可靠区分手的身份；本版采取暂停与重新就绪。红绿优先作为第一轮实物验证配置。

本记录只确认初步开发与自动/模拟验证，不将 B1/B2 的真人项或 J1 现场验收标为完成。
