# 规则 v2.4 验收 · 2026-11-07

本轮完成吸引球和排斥球在释放效果期间固定位置、结束后恢复普通碰撞。规则见 [v2.4 说明](../../游戏规则变更-v2.4.md)。

## 实现

先前效果源仍为可移动物体，会被吸来的邻球或其他来球撞离触发点。现在进入 active 状态时将自身设为静态碰撞体并清零速度，350ms 后恢复原质量、惯量、摩擦和恢复系数。等待触发阶段保持正常物理。暂停冻结计时；重开、回滚、离场与销毁均清理固定状态。边界反射跳过固定球，避免静态无穷质量造成无效数值。

两种球共用这一处理，效果强度、范围、持续时间以及本投结束后失效的规则不变。
