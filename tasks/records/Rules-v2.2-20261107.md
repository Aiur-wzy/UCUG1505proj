# 规则 v2.2 验收 · 2026-11-07

> 本文保留 v2.2 历史记录。墙壁反弹和粘黏组合物理已由 [v2.3 修订](../../游戏规则变更-v2.3.md) 覆盖。

根据用户试玩反馈，完成特殊效果仅在本球发射轮次有效、180° 瞄准、减少滑行与撞墙损耗、最大初速度 35，以及排斥与吸引等强度。当前规则和参数见 [v2.2 说明](../../游戏规则变更-v2.2.md)。v2.1 的报告作为历史证据保留。

## 根因与修正

旧粘黏球在本轮未碰球时保持 `ready`，碰撞处理也允许任何 `ready` 的旧球发起连接，因此后续投掷会意外触发旧球。现将发起者限定为当前 `activeShot.shotId`，并在结束时将未使用的粘黏能力置为 `done`。吸引、排斥原有状态机完成后不会重启；本次同样限制到当前投掷 id，并在回合结束时清理效果状态。

角度限制集中于 defaults 的 `shotLimits`，同时用于 host 公布/校验、鼠标键盘截断和滑杆显示。墙壁单独使用 0.85 的恢复系数，普通球间恢复系数保持 0.7；预测反弹同步使用墙壁参数。

## 实际验证

Windows x64、独立 Node 24.22.1、Edge 156.0.4314.58。类型检查、**78 项 Vitest 测试**和构建通过；开发版 5173 与构建版 4173 的浏览器脚本分别通过 **22 项检查**，均无运行或资源错误。

| 场景 | 实际结果 |
| --- | --- |
| 粘黏空投后被撞 | 先投粘黏 0°/11%，未碰球即结束；状态 `done`、激活数 0。后投普通 0°/14%，捕获真实球间碰撞且旧球移动超过 5 单位；全程无粘黏约束，激活数仍为 0 |
| 旧吸引 / 排斥被撞 | 分别先投特殊球并完成效果，再以普通球真实碰撞；旧效果全程 `done`、激活数仍为 1，效果状态无变化 |
| 当前粘黏仍有效 | 普通 0°/11% 后粘黏 0°/14%，首次碰撞生成一条连接；暂停保持位置，恢复停稳后解除；后续投掷不再次激活 |
| 180° 角度 | 滑杆、方向键、鼠标均达到 −90° 和 +90°；host 接受并冻结端点及 ±75°，拒绝超过 ±90° 的输入；满力度左右水平投掷均正常反弹 |
| 自然损耗 | 真实 Matter 初速度 35，下一自由滑行步速度比为 0.985，即自然损耗 1.5% |
| 撞墙损耗 | 同样的 35 初速度、0.015 自然损耗，单独比较旧/新墙壁系数：0.7 时反向步速度保留约 66.41%，0.85 时约 80.96%。实际比率包含该步自然损耗与碰撞求解，不将参数 0.85 冒充实测保速率 |
| 吸引与排斥 | 纯规则验证同距离冲量大小相等、方向相反，范围 150、持续 350ms。真实两球初距约 118.50，排斥后约 159.79，吸引后约 71.34；位移不同源于作用过程中距离与衰减持续变化 |
| 三面墙与开放底边 | 最大力度在顶墙、左右墙均反弹；顶墙反弹后可从下边离场，水平投掷留在场内；重开只保留 3 面墙 |
| 五个单人关卡 | 每关相同四次合法投掷实得 9 分，达到 3/4/5/6/7；最低力度水平投掷得 0 分并可重试 |
| 三场双人八投 | 每人四球各 1 只，轮换和重赛先手正确，比分 0:1 / 1:0 / 0:1；全部效果完成，无连接残留 |
| 既有交互 | 正式页隐藏预测、调试开关不改状态、实时按键投掷、锁定取消、模拟体感、重复 FIRE、暂停、390px 无横向溢出及本地 OpenCV 合成图继续通过 |

五关复现：普通 −9°/11%，吸引 0°/11%，粘黏 +9°/11%，排斥 +20°/10%。这些整局通过真实 host 命令进入同一 Phaser Matter 世界，不注入比分、库存或球的位置。

测试保留两个明确区分的物理夹具：底边测试直接生成朝下的球；撞墙对比暂用旧系数 0.7，结束后恢复配置值 0.85。它们用于局部物理验证，不冒充正常整局玩法。
