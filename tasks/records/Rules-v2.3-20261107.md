# 规则 v2.3 验收 · 2026-11-07

本轮完成两项反馈：四种球低速碰墙反弹、粘黏组合的单球质量与滑行衰减。规则见 [v2.3 说明](../../游戏规则变更-v2.3.md)。旧版本报告保留为历史证据。

## 根因和改动

在近墙位置分别构造普通、排斥、吸引、粘黏球，以 0.2 / 0.5 / 1 / 2 等速度撞墙，旧版本均出现法向速度没有立即反向、随后接近零的现象。该问题来自原生静止接触/多接触点求解，不能只修改排斥球参数。现通过 `walls.ts` 统一执行三面边界反射，墙体设为传感体以避免原生冲量重复结算；球间接触保留原引擎处理。

旧粘黏连接将两球速度按质量平均，静止目标会使速度减半，并保留双球总质量。新实现保留发射球速度、每成员半质量、相同空气阻力，禁用内部碰撞并从约束静止长度开始连接。组合整体反弹，解除连接时恢复质量、惯量和碰撞设置。
