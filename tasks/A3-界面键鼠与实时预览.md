# A3：界面、键鼠与实时预览

负责人：A。状态：待实施。关联验收：G01、G05、C03。先交付可操作界面，装饰在 A4 补齐。

## 1. 玩家应看到什么

进入简明菜单，选择单人/本地双人及键鼠/手套方式。局内能看到当前玩家、剩余球类、操作阶段、角度、力度、预计路径与锁定提示；可以取消、暂停、重试和回到菜单。结果页说明是否过关或双方得分，并提供下一关/重赛。

手套方式下始终保留键鼠选球、Enter 锁定、Space 发射和 Esc 取消。A3 将输入转换为合同命令；不直接扣库存、建物理球或改变回合。

依据：[总体手册](../Flock-and-Flick-开发手册-v2.0.md)第 5、6、14、18 节；[公共合同](../interface-v1.1/contract.ts)。

## 3. 输入与绘制要求

1. 选球只在 select 生效：点击库存项或数字 1、2。零库存禁用；后续增加球类时按配置顺序生成，不把两种球写死到游戏规则里。
2. 键鼠占用预览时，在画布内移动鼠标改变方向，滚轮或上下键调力度；左右键每次 1°，上下每次 0.05。用画布反变换后的逻辑坐标和本投起点计算角度，发送前限幅。
3. adjust 每次接受预览后，在下一绘制帧更新角度、力度、箭头和 A2 的预计线；不等停留、不等锁定。标签明确写“预计”，首个碰撞/出界处显示标记。
4. Enter 提交空载荷 ARM_SHOT；armed 显示冻结值，Space 只发空载荷 FIRE；Esc 在 armed 回 adjust，在 adjust 回 select。收到拒绝时保持权威状态并给出简短提示。
5. 手套拥有预览时，单纯移动鼠标不抢占。方向键、画布内滚轮或“键鼠接管”按钮才切到键鼠；“手套接管”按钮恢复体感。切源后按合同清锁并保留可见值。已经由键鼠占用时，armed 的方向变化不能改写锁定值。
6. 离散确认键忽略自动重复。输入框、按钮、文本框或选择框聚焦时不触发游戏快捷键；点击画布可恢复游戏焦点。不要拦截整个页面的正常键盘与滚动。
7. 校准/暂停/结果与菜单属于产品状态，不直接等同于 Phaser Scene 生命周期。界面始终从 A1 读取允许操作，避免自己维护另一套阶段。
8. 追踪丢失时显示原因、冻结的最后有效预览和键鼠接管入口。体感错误不遮住所有游戏控件；正在运行的球仍继续，除非用户主动暂停。
9. Scene shutdown、重开和页面退出解绑自己注册的监听/计时，销毁旧预览对象；声音未解锁不能阻止开始游戏。

游戏逻辑与体感确认开关不需要占据主菜单。首版只把必要的操作说明和状态显示给玩家，实验开关可放诊断面板。

## 4. 独立浏览器验收

不为普通排版新增测试框架。先用调试页切换模拟状态检查显示，再接真实 A1/A2。下列操作在 dev 和构建 preview 各做一遍：

| 编号 | 前置与操作 | 通过条件 |
| --- | --- | --- |
| A3-01 | 从菜单开始，选择一种有库存的球 | 当前玩家、库存与阶段可辨识；进入 adjust；球还未发射也未扣库 |
| A3-02 | 连续改变角度与力度，不执行锁定 | 数值、箭头、力度条、预计线持续更新；无停留确认要求 |
| A3-03 | Enter 后移动输入，再按 Esc | 锁定期间画面与锁定值一致；取消后返回实时调整；库存不变 |
| A3-04 | 再锁定，按住 Space；场景重开后再发射 | 每次合法动作只发一球；长按与监听残留不造成重复投掷 |
| A3-05 | 模拟 motion 预览；移动鼠标，然后按方向键，再点手套接管 | 移动鼠标不抢占；显式键鼠操作切源；手套可恢复；来源状态有明确显示 |
| A3-06 | motion 预览时分别使用数字选球、Enter、Space、Esc | 相应合法阶段键鼠均有效；不会被 motionActionsEnabled 禁用 |
| A3-07 | 焦点放在校准按钮/输入框，再按 Enter、Space；点击画布后重试 | 聚焦控件时只执行控件行为；画布恢复焦点后游戏键正常 |
| A3-08 | 调整窗口尺寸/显示缩放，鼠标指向逻辑起点左右 | 输入方向与显示一致；界面可用，无额外偏移；布局不遮住关键控件 |
| A3-09 | 手套掉线、暂停、回菜单再开始 | 有可读提示和键鼠入口；暂停按规则清锁；新会话无旧预览监听/命令 |
| A3-10 | 进入通过、失败与双人结果的模拟状态，再接 A4 实际结果 | 显示正确行动按钮；不会自行计算比分或换人 |
