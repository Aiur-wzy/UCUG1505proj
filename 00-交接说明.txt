阅读顺序
Agent 先读 AGENT-交接说明-v2.0.md，再按职责阅读两本手册和接口文件。
当前电脑按配置手册第 3 节；其他电脑按第 4 节独立自查。
确认 Node 24.x，在 stack-starter-v2（包含 package.json）执行 npm ci。
Windows PowerShell 使用 npm.cmd；其他系统使用 npm。

本包不含 node_modules、dist、生成的 Worker 或本机日志。
dev / build 自动预构建 Worker；每台电脑按同一锁文件安装依赖。
现有工程用于验证技术链，尚非最终游戏。真实摄像头与手套仍需本人验证。
八张执行任务卡已编写；功能实施与验收仍待进行，不能把卡片的预期结果当作测试记录。
